# Regra de impressão preservada

O mecanismo de impressão que já funcionava não deve ser refeito nesta versão.

- Venda deve ser persistida antes da pergunta de impressão.
- Perguntar: "Deseja imprimir?"
- SIM: executar a impressão existente.
- NÃO: zero chamadas de impressão.
- Reimpressão também pede confirmação.
- Não alterar driver, spooler ou fluxo físico de impressão sem necessidade funcional comprovada.
